# Правила работы с проектом

Перед изменениями прочитать `README.md` и `docs/MODEL.md`, затем изучить затронутый код и тесты. Запрос на изучение или планирование остаётся read-only; реализация требует явного запроса пользователя.

## Источники и границы

- Рабочие входы находятся только в `data/`. Не создавать второй набор и не вшивать числа из UI в алгоритмы.
- Различать `CASE_INPUT`, `TEAM_DECISION` и `TEAM_ASSUMPTION`; неизвестные параметры не заполнять догадками.
- FastAPI/DTO/хранилище находятся в `src/app/`, расчёт — в `src/engine/`, представление — во `frontend/`.
- UI и экспорт используют результат ядра. Бизнес-формулы во frontend не добавлять.
- `frontend/src/api/schema.d.ts` генерируется из OpenAPI и вручную не редактируется.
- Не создавать фиктивный optimizer, нулевые результаты или SYNTHETIC-данные под видом расчёта.

## Неподвижные правила модели

Соблюдать `docs/MODEL.md`: critical входит в total; состояния поставки/оплаты/запаса не смешиваются; запас неотрицателен, shortage отдельный; потери считаются один раз; 45-дневный резерв физический; BASE детерминирован; take-or-pay и reservation разделены; mandatory stress не смешивается с исследовательскими сценариями.

## Изменения и проверки

- Сохранять неизвестные поля плана и optimistic `expected_revision`.
- После изменения API запускать штатные генераторы OpenAPI и frontend types.
- Для затронутого кода запускать соответствующие Python/frontend тесты. Полная проверка: pytest, OpenAPI/type checks, frontend tests/build и Compose config.
- Прохождение тестов транспорта или UI не означает математическую приёмку. Не менять `model_verified=false` без отдельного доказательства.
- Не скрывать failures через skip/xfail, `assert True` или чтение ожидаемого результата как фактического.

## Git и безопасность

- Сохранять чужие изменения в dirty worktree. Не выполнять reset/clean, не переписывать историю и не делать commit/push без отдельного разрешения.
- Не добавлять секреты, ключи, личные `.env` или способы обхода доступа.
- После работы назвать изменённые файлы, фактически запущенные проверки и оставшиеся ограничения.
