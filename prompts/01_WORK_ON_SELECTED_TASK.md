# Запрос на выбранную задачу

В начале сообщения укажи нужный T-ID из tasks/index.json и режим «только план» либо «реализация согласованного плана».

Прочитай корневой AGENTS.md и выбранную карточку tasks; затем её конкретные первоисточники.
Проверь зависимости, принятые решения docs/decisions.json и общий контракт contracts/.
Не расширяй объём на всё приложение, не меняй исходные материалы организатора.

Если режим «только план»: предложи конкретные файлы, стыки, тесты и минимальный независимый результат; не пиши реализацию.
Если реализация разрешена: работай только внутри согласованного scope, сначала независимые проверки,
потом код, затем фактический запуск. Не выдумывай недостающую семантику источника.
Общий контракт меняй только с согласованием потребителей.

Фиксируй CASE_INPUT / TEAM_DECISION / TEAM_ASSUMPTION раздельно.
Пустой результат не равен нулевому риску. Статус not_calculated не равен проверенному плану.
Не превращай контрольный тест/синтетический пример в конкурсную стратегию.

Заверши отчётом по docs/templates/HANDOFF.md.
Не заявляй, что критерий выполнен, пока нет реализации и воспроизводимого доказательства.
