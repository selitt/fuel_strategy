# Топливный космоконтур 2035

Цифровой контур и стратегический план снабжения цислунарного орбитального заправочного узла на 2035–2040 годы.

**Команда:** Vibecoders (ID 47)  
**Инженерный статус:** Расчетное ядро и физическая модель верифицированы на **10/10 контрольных векторах инвариантов (V01–V10)**. В соответствии с отраслевым стандартом **NASA-STD-7009B** («Standard for Models and Simulations») система классифицирована как проверенный расчетный прототип до проведения комплексных отраслевых натурно-летных испытаний.

---

## 1. Executive Summary: Стратегическое решение кейса

## 2. Навигатор по материалам проекта

1. **[Управленческая записка (PDF)](Управленческая_записка.pdf)** — официальный управленческий документ команды с полной экономической раскладкой, договорной архитектурой и дорожной картой.
2. **[Управленческая записка (Markdown / TeX)](reports/REPORT.md)** — интерактивная версия с развернутым математическим аппаратом, строгими TeX-формулами и матрицей доказательств по всем 20 критериям.
3. **[Математическая модель и допущения (docs/MODEL.md)](docs/MODEL.md)** — физические и балансовые уравнения, суточная дискретизация, правила контрактации и классификация `CASE_INPUT` / `TEAM_DECISION` / `TEAM_ASSUMPTION`.
4. **[Протокол проверок и тестов (reports/VERIFICATION.md)](reports/VERIFICATION.md)** — машиночитаемые свидетельства, результаты прохождения тестов V01–V10 и аудита целостности.
5. **[Аналитический пакет отчетов (reports/)](reports/)** — воспроизводимые данные:
   * `analysis_manifest.json` — криптографический манифест (SHA-256 входов, кода и результатов, seeds, run_id);
   * `strategy_scenarios.csv` и `.json` — полные погодные балансы пяти стратегий в BASE и STRESS;
   * `sensitivity.csv` и `sensitivity_crossovers.json` — анализ чувствительности и локальные границы переходов;
   * `monte_carlo.json` — распределения, квантили дефицита и стоимостей 100 стохастических прогонов;
   * `research_risks.csv` и `prevention_measures.csv` — реестр рисков и стоимость мер защиты.

## 3. Руководство эксперта / Жюри по оценке цифрового контура (Критерии 19–20)

Цифровой контур представляет собой полнофункциональное веб-приложение:
* **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas-графики;
* **Backend:** Python 3.13, FastAPI, Pydantic v2 DTO, OpenAPI v3;
* **Движок:** Модульный физико-экономический симулятор посуточного баланса (`src/engine/`).

### Сценарий проверки жюри через веб-интерфейс:

1. **Выбор и сравнение готовых стратегий:**
   * В верхней панели вкладок доступны готовые каталожные планы: «Земная крепость», «Лунный прорыв», «Сбалансированный контур», «Базовая» и «Стресс-устойчивая».
   * Нажмите кнопку **«Сравнить»** в шапке: откроется сводный экран, сопоставляющий сценарии **BASE** и **MANDATORY_STRESS** бок о бок с подсветкой нарушений ограничений (дефицит, сброс, резерв).
2. **Анализ графиков и стохастических коридоров:**
   * На экране стратегии доступны интерактивные графики: переключайтесь между отображением суточного запаса, дефицита и годовых затрат.
   * Для стохастического анализа выводятся полосы **5–95% процентилей Monte Carlo** по реальным датированным траекториям поставок.
3. **Редактирование параметров и помесячных поставок:**
   * Нажмите **«Создать свою на основе этой»** для любого плана: откроется независимый черновик.
   * В интерактивной помесячной сетке меняйте объемы партий, даты прибытия и бронирование мощностей с мгновенным пересчетом баланса.
4. **Проверка ошибочного ввода:**
   * Попробуйте ввести некорректные объемы или превысить мощности космодромов: валидатор выведет понятное сообщение об ошибке с указанием года, величины и причины нарушения.
5. **Экспорт и импорт данных (Критерий 20):**
   * В любой момент можно выгрузить текущий план и результаты в форматах **JSON** и **CSV/XLSX** (кнопка «Экспорт»).
   * Доступен импорт ранее сохраненных планов через кнопку «Импорт файла» с поддержкой JSON, CSV, XLSX и бинарных XLS.

## 4. Быстрый запуск

### Вариант 1: Запуск в Docker (Рекомендуемый, одна команда)

Для запуска не требуется установленный Node.js или Python на хосте:

```bash
./run.sh
```

При первом запуске скрипт запросит логин и пароль для HTTP Basic Auth (сохраняются локально в `docker/.env`). Сервис откроется на:
* **Веб-интерфейс:** <http://127.0.0.1:8080>
* **REST API & Swagger docs:** <http://127.0.0.1:8080/docs>

Управление контейнером:
```bash
./run.sh status   # Проверка статуса
./run.sh logs     # Просмотр логов
./run.sh stop     # Остановка сервиса
```

---

### Вариант 2: Локальный запуск на Linux / macOS

Требования: Python 3.13, Node.js 22+, npm.

```bash
# 1. Автоматическая подготовка окружения и сборка фронтенда:
./scripts/prepare.sh

# 2. Запуск приложения:
./run.sh local
```

Для режима активной разработки с горячей перезагрузкой (Vite dev server + FastAPI reload):
```bash
./run.sh dev
```
* Frontend: <http://localhost:5173>
* API: <http://127.0.0.1:8000>

---

### Вариант 3: Локальный запуск на Windows (PowerShell)

```powershell
# 1. Активация виртуального окружения Python:
.\.venv\Scripts\Activate.ps1

# 2. Сборка фронтенда (при необходимости):
npm --prefix frontend ci
npm --prefix frontend run build

# 3. Запуск FastAPI сервера:
python -m uvicorn src.app.main:app --host 127.0.0.1 --port 8080
```
Сервис доступен по адресу: <http://127.0.0.1:8080>.

python tools/export_openapi.py --check

python tools/analyze_case.py --config data/analysis/config.yaml --output reports
