# Топливный космоконтур 2035 · рабочее пространство команды

**Начните с [START_HERE.md](START_HERE.md).** Это каркас для пяти участников и работы с Codex, **не готовое приложение и не решение кейса**.

## Проблема продукта

Оператор условного орбитального топливного узла должен обеспечивать растущий спрос на 2035–2040 годы. Низкая цена топлива недостаточна: заказ может прийти поздно, резерв мощности не находится в баке, контракт может требовать оплатить невыбранный объём, а новые мощности требуют денег и времени. Нужно сопоставлять стоимость жизненного цикла, надёжность снабжения и гибкость решений. Основание: [постановка, с. 2](docs/Task/Постановка_кейса_—_Топливный_космоконтур_2035_КосмоХакатон_2026.pdf#page=2).

**Будущий продукт:** инструмент, в котором оператор меняет закупки, резервы, контракты и инвестиции, получает пересчитанные поставки, запас, дефицит, обслуживание спроса, расходы и нарушения; затем сравнивает сценарии, сохраняет и выгружает план. Подробнее: [PRODUCT.md](docs/PRODUCT.md).

## Что подготовлено

Материалы организатора; все 20 критериев; контрольные правила; границы модулей; смысловые контракты; задачи и зависимости для пяти направлений; шаблоны допущений и доказательств; инструкции агентам; проверка целостности рабочего пространства.

**Чего ещё нет:** расчётного ядра, алгоритма выбора стратегии, пользовательского приложения, посчитанного BASE/STRESS и готовой защиты. Команда уже выбрала Python/FastAPI/Pydantic для backend и расчётного слоя, React/TypeScript/Vite/Plotly для интерфейса и Docker Compose для локального запуска. Solver, численные допущения и продуктовая приёмка ещё не реализованы. Python helper проверяет только комплект.

## Проверка комплекта, не решения

Из корня, Python 3.10+ для служебного инструмента:

```bash
python3 tools/workspace.py check
python3 -m unittest discover -s tests/workspace -v
```

Windows: `py -3` вместо `python3`. Устанавливать пакеты не нужно. Фактически проверенная среда — в `docs/provenance/BUILD_VERIFICATION.md`. Эти команды не рассчитывают снабжение и не подтверждают конкурсные баллы.
