# С чего начать

**Команда — 5 человек. Кейс выбран: «Топливный космоконтур 2035». Сейчас — подготовка разработки, не выбор закупочной стратегии.**

## 1. Понять смысл

Прочитайте [PRODUCT.md](docs/PRODUCT.md). Делаем инструмент, который показывает: **что заказать → когда придёт → хватит ли топлива → сколько стоит → где нарушаются ограничения → что меняется при другом плане или стрессе**. Не симулятор ракеты, не прогноз нефти, не блокчейн и не задача ВКД.

## 2. Открыть рабочий корень

Распакуйте архив в **новую папку**, откройте её целиком в редакторе либо через `fuel.code-workspace`. Не запускайте агента из `fuel-hackathon/test_oil`: там исходники организатора, не наше приложение. Для существующего Git сначала прочитайте [IMPORT_AND_GIT](docs/IMPORT_AND_GIT.md).

Для чтения ничего устанавливать/клонировать не нужно: PDF, пять CSV, два сценария и README уже внутри. Проверка комплекта: `python3 tools/workspace.py check`; Windows: `py -3 tools/workspace.py check`.

## 3. Дать Codex первый запрос

Откройте Codex в корне и передайте [prompts/00_START_IN_CODEX.md](prompts/00_START_IN_CODEX.md). Это **ориентация и T00**, не приказ написать всё приложение. Постоянные правила проекта — [AGENTS.md](AGENTS.md).

Агент должен отделить имеющиеся материалы от ещё не реализованных функций, назвать необходимые решения и предложить следующий ограниченный этап. Не должен выбирать за вас неизвестные коэффициенты и представлять пустые тесты как готовое решение.

## 4. Согласовать, затем разделять

В [T00](tasks/T00_START_AND_DECISIONS.md) выбираем стек, владельцев пяти направлений и нужные трактовки. В [T01](tasks/T01_DATA_AND_CONTRACTS.md) согласуем формат обмена. Затем выдаём задачи по [зависимостям](tasks/README.md).

Имена, сроки, ставка, шаг времени, риск-модель и готовые закупки не выдуманы. [Открытые вопросы](docs/OPEN_QUESTIONS.md) разделяют решения команды и уточнения организатора; они блокируют только зависящие от них части, не всё проектирование.

## 5. Не перепутать готовность

**Есть исходники — ещё нет модели. Есть схема — ещё нет бизнес-валидации. Проверка каркаса прошла — это не V01–V10 и не баллы жюри.**

Все 20 критериев пока `not_started`, доказательств реализации нет. [Приёмка](docs/ACCEPTANCE.md) описывает, что позднее показать.
