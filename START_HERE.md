# С чего начать сейчас

Кейс — «Топливный космоконтур 2035», команда из пяти человек. Рабочая точка: HTTP API подготовлен к разработке UI; React-сайт ещё не написан, математическая модель остаётся отдельной работой.

Для запуска откройте [API_README](API_README.md). Для разделения работы с Васей — [TEAM_AND_NEXT](docs/api/TEAM_AND_NEXT.md). Что исправлено и проверено в этой передаче — [HANDOFF](docs/api/HANDOFF.md).

Распакуйте полный архив в отдельную папку. При переносе в действующий репозиторий не заменяйте `.git`, не перезаписывайте изменённые коллегами файлы; используйте overlay и сверку SHA-256. В исходном `9(1).zip` было незавершённое слияние: исправленный `main.py` сам по себе не завершает Git merge на вашем компьютере. После ручной проверки конфликта отметьте только согласованный файл как разрешённый.

## Что делать параллельно

Вася ведёт расчётные DTO и адаптер модели. be0h ведёт HTTP, проекты/файлы/ошибки и frontend. Три участника ведут математику. HTTP и UI передают результаты без собственной копии формул.

Фронт начинает с одного сквозного пути: шаблон или импорт плана → сохранение проекта → правки → расчёт → таблицы/нарушения → сравнение → выгрузка. Точные поля берутся из текущей OpenAPI, а не из ранних планов.

## Проверки

```bash
python -m pytest -q
python tools/export_openapi.py --check
python tools/workspace.py check
```

Первая команда проверяет доступные тесты API и workspace. Вторая выявляет рассинхронизацию опубликованной схемы. Третья — только целостность материалов. Они не подтверждают V01–V10 или конкурсные баллы.

Исходники кейса: `fuel-hackathon/test_oil/`, PDF: `docs/Task/`. `fuel-hackathon/test/` относится к другому кейсу и не используется в backend. Старые планы `tasks/`, `prompts/`, `WORK_ORDER.md` остаются историей командной организации, не заменяют актуальный HTTP-контракт.
