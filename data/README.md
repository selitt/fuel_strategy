# Рабочие входные данные

Этот каталог содержит рабочую копию входов кейса для API и проверок:

- пять исходных CSV-таблиц в корне каталога;
- канонические сценарии в `scenarios/`;
- JSON-схемы в `schemas/`;
- переносимые примеры в `examples/`;
- контрольные случаи V01–V10 и ожидаемые проверки в `validation/`.

Оригинальный полный snapshot сохранён без изменений в
`fuel-hackathon/test_oil/`. Рабочая копия синхронизирована с commit
`cec6de1950276091689e71a67f9a875fb4ca6213`; обновлять её нужно явно из
этого snapshot и проверять совпадение файлов.

Runtime-проекты API хранятся отдельно в `.local/projects` и не являются
входными данными кейса.
