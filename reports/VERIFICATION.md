# Протокол проверок

Проверки относятся к текущему рабочему дереву, включая сохранённые параллельные изменения. Они не являются независимой математической приёмкой или подтверждением работы публичного развёртывания.

## Контрольные примеры

Команда: `.venv/bin/python -m pytest -q tests/test_control_vectors.py`.

Результат: **10 passed**. Покрыты V01–V10 на явно синтетических входах через производственный расчётный код. Первый прогон дал 9 passed / 1 failed: отсутствовал общий расчёт пропорциональной платы за резервирование V05. После его добавления все десять примеров прошли.

V05 проверяет общий денежный расчёт для половины года. Контракт пользовательского плана по-прежнему задаёт годовую бронь; поддержка полугодовых контрактов интерфейсом не заявляется.

## Представление риск-анализа

Команды после транспиляции затронутых TypeScript-модулей штатным TypeScript API:

```text
node --test tests/risk.test.mjs
npm run typecheck
```

Рабочий каталог: `frontend/`. Результат: **7 passed**, TypeScript typecheck — **exit 0**. Новый тест сначала завершился ошибкой из-за отсутствующей функции проверки финансовой сводки, затем прошёл после реализации. Проверены отсутствие выдуманных нулевых затрат у старого результата, конечность чисел и сохранение серверных статистик. React-разметка проверена TypeScript; браузер в этом этапе не запускался.

После транспиляции текущих `lib`/`api` также выполнена команда `node --test tests/api.test.mjs`: **18 passed**. Проверены транспортные ошибки, optimistic revision, импорт/экспорт и сохранение серверных значений при сравнении.

## Аналитический пакет

```text
.venv/bin/python -m pytest -q tests/test_analysis.py
.venv/bin/python tools/analyze_case.py --config data/analysis/config.yaml --output reports
```

Результаты: **15 passed**, генератор — **exit 0**. Финальный `run_id=b4b77a066a784369`: проверены SHA-256 всех 13 входных файлов, 13 файлов кода и 7 выходных файлов. В пакете 10 сочетаний стратегии/сценария (60 годовых строк), 780 строк чувствительности, 27 строк последствий рисков, 8 сравнений защитных мер и 12 записей Monte Carlo. Основные MC-сравнения используют 100 прогонов для каждого из seeds 42/43/44; варианты мер — 100 прогонов с primary seed 42.

Проверены поиск локальных переходов без предположения глобальной монотонности, отдельный статус номинального пересечения стоимости, выбор только выполнимого кандидата, отсутствие мутаций исходных данных, отклонение неподдерживаемого дисконтирования и сохранение происхождения результатов. Ранее во время параллельной правки календарей защита генератора обнаружила изменение входов и прервала расчёт; итоговый пакет сформирован после завершения этих изменений. Публикация записывает манифест последним; hashes позволяют обнаружить неполный или смешанный пакет.

## Границы

Полная сборка, Docker, браузер, публичный туннель и сетевые проверки не запускались. Прохождение отдельных тестов не меняет `model_verified=false`.
