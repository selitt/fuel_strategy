# Будущая приёмка продукта

Подробные процедуры, связанные критерии и задачи находятся в [catalog.json](catalog.json).
Все состояния `not_implemented` честно отражают отсутствие расчётного приложения.
При реализации добавить реальные входы, вызовы, ожидаемые/фактические значения, команды и воспроизводимые результаты.
Обзор: [ACCEPTANCE.md](../../docs/ACCEPTANCE.md).
