# Проверки

`workspace/` — исполняемые тесты **служебного каркаса**, не физики и не финансов.
`acceptance/catalog.json` — описания будущей приёмки продукта, не автоматические тесты и не PASS.
Контрольные примеры организатора остаются в `fuel-hackathon/test_oil/validation/`.

После G0 каждый владелец добавляет тесты своего модуля в принятом стеке; сквозные — в T06.
Не имитировать реализацию `assert True`, сравниванием константы с ней же, пропуском обязательных тестов или фиктивным отчётом.
