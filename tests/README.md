# Проверки

`api/` — реальные HTTP-тесты FastAPI через TestClient с изолированным временным JSON-хранилищем: контракт, проекты/ревизии, импорт, экспорт, ошибки, CORS и границы сериализации. `test_calc_api.py` проверяет базовый расчётный API, но не доказывает полноту модели.

`workspace/` — исполняемые тесты служебного каркаса, не физики и не финансов. `acceptance/catalog.json` — описания будущей приёмки продукта, не исполняемые проверки и не PASS. Рабочие контрольные примеры находятся в `data/validation/`; оригинал остаётся в `fuel-hackathon/test_oil/validation/`.

Из корня проекта:

```bash
python3 -m pytest -q
python3 -m pytest tests/api/test_json_boundaries.py -q
python3 tools/export_openapi.py --check
python3 tools/workspace.py check
```

Количество тестов меняется вместе с кодом; результат каждого прогона фиксируется фактическим выводом команды. API-тесты не доказывают полноту математической модели.

Нельзя заменять проверки фиктивными сравнениями, ослаблять утверждения ради PASS или скрывать проблемы через skip/xfail. В каждом новом модуле сохранять независимые тесты и явно отличать транспортную проверку от математического эталона.
