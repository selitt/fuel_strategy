# Исходный код

`app/api/` — FastAPI, подключение адаптера, обработка HTTP-ошибок и файлов.
`app/dto/calc_dto.py` — расчётные DTO Васи; `app/dto/web_dto.py` — проектные/HTTP-обёртки.
`app/service/calc_service.py` — адаптер текущего движка, зона Васи и команды модели.
Остальные `app/service/` — импорт, сохранение, структурная проверка, экспорт; без формул модели.
`app/persistence/` — локальное JSON-хранилище проектов, один процесс backend.
`engine/` — расчёты, зона трёх участников математического направления.
