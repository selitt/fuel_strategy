## Последовательность

```text
T00 → T01 → T02 ─┐
           T03 ─┼→ ранний срез T06 → полный T06 ─┐
           T04 ─┘                               ├→ T07 → T08
           T05 ─────────────────────────────────┘   └→ B01 (опция)
```

T02/T03/T04 стартуют параллельно после согласованных контрактов T01; T05 — методика и источники.
Первое соединение T06 не откладывать до завершения всего: передавать совместимые малые части.
Финальный T06 включает полные модули и пользовательскую приёмку. T07 запускает реальные исследования, не фикстуры.
B01 не блокирует основную сдачу.

Карточки описывают объём и приёмку. После подтверждения оставшихся решений агент декомпозирует **одну выбранную карточку**
на реальные файлы и небольшие тестируемые изменения; не пишет всё приложение одним заданием.
