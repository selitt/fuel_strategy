# Справочные материалы

Оба вложенных каталога — исходные материалы, а не место реализации приложения.
`test_oil` относится к выбранному топливному кейсу; `test` — другой кейс и исключён из расчётной логики.
Не менять исходные файлы, схемы, CSV, YAML, примеры, скрипты и README ради удобства решения.
Контрольные суммы хранятся в корне в sources.lock.json.

Вернитесь к корневому AGENTS.md и выбранной карточке tasks.
Особенно не копируйте `test/case_core.py` в топливную модель.
Вложенный validate_reference_repo.py проверяет исходный комплект, не наше приложение.
