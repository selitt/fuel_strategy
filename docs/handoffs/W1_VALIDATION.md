Версия общего контракта пока не принята. На стыке с W3 нужно подтвердить раздельные поля `capacity`, `reserved`, `ordered`, `paid`, `delivered`, `inventory`, `served`, `shortage`; критический спрос входит в total; физический запас неотрицателен; потери считаются один раз от валового поступления; 45-дневный reserve проверяется на начало каждого года сценария. Календарь и порядок событий остаются открытыми (Q03–Q05, Q11).

## Проверки на своей машине

Выполнить без установки пакетов и без запуска приложения:

```bash
git status --short --branch
python3 --version
uv --version
node --version
npm --version
docker --version
docker compose version
python3 -S tools/workspace.py check --json
python3 -S -m unittest discover -s tests/workspace -v
git diff --check
```

В отчёт добавить ОС, архитектуру, shell и фактический вывод команд. На Windows использовать `py -3`; наличие Docker CLI не считать работающим daemon. V01–V10 на этом шаге не запускались и не должны быть объявлены пройденными.
