# Интерфейс оператора — согласованный дизайн

Запрос и подтверждение: спокойный, понятный, красивый интерфейс, умеренные анимации; готовый ZIP всего проекта. Не разрабатывать математику. Основа — 11.zip.

## Продукт
Четыре раздела: Обзор, План, Сравнение, Данные. Нативные таблицы и формы вместо сетки карточек. Проекты доступны через переключатель. Одна основная кнопка «Рассчитать», автоматически сохраняющая текущий план до расчёта. Дополнительные операции проекта находятся в меню.

## Визуальный язык
Графит #15181d, панель #1b1f26, границы #303640, текст #edf0f5, вторичный текст #a5adbc, холодный синий акцент #a9c9ff. Ошибки — текст и иконка, не только цвет. Системный стек Segoe UI / system-ui обеспечивает кириллицу без загрузки шрифтов. Отказ от градиентных карточек и имитации телеметрии. Узкая боковая навигация, большие рабочие таблицы, график как главный визуальный элемент результата.

## Поведение
Нет расчётных данных до реального ответа API. Все численные результаты приходят из backend. Интерфейс форматирует значения и рисует графики, не реализует физические или финансовые формулы. Показывает годовые уровни сервиса, не заменяет их средним. Прототип обозначен одним постоянным, спокойным сообщением; отсутствие риска/внутригодовых рядов не представлено нулями. При редактировании результат становится неактуальным, экспорт результата недоступен до пересчёта. Импортированные результаты маркируются.

Сохраняются расширения DTO. Не объединять дубли строк плана молча; исходные заказы редактируются построчно. Инвестиции имеют investment_id и year без интерпретации даты UI. Источники и годы берутся из каталога и самого плана. Не менять CSV: каталог read-only. Импорт плана и проекта JSON, экспорт проекта и результата через существующие ручки. Сравнение 2–6 сохранённых актуальных результатов без ранжирования; выгрузка сравнения содержит именно ответ API.

## Архитектура
React + TypeScript; обычный CSS; Vite для разработки/production-сборки. API-типы генерируются из docs/api/openapi.json. Чистые функции редактирования и форматирования отдельно от React; единый HTTP клиент; state controller отвечает за ревизии и сохранение. Диалоги используют нативный dialog с фокусом и Escape. Reduced motion и клавиатурная навигация обязательны.

Backend и UI доступны с одного origin: отдельный ASGI entrypoint отдаёт статическую сборку, существующий app/engine не переписывается. Один Uvicorn worker и постоянный volume для JSON-хранилища. Docker multistage для сборки из исходников; локальный/облачный запуск документирован. Shared workspace, не многопользовательская платформа. Опциональный HTTP Basic access gate для закрытого командного развёртывания; публичный адрес требует HTTPS.

## Приёмка
Исходные API-тесты + новые веб-тесты; чистые UI-функции; браузерный путь через реальный backend; desktop/mobile screenshots; отсутствие ошибок консоли. Сборки Docker/npm подтверждаются только фактическим запуском. Исходники engine/DTO/адаптера/KosmoAPI/reference/data должны совпасть по SHA256.
