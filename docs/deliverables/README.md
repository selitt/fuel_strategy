# Итоговые материалы: заготовки, не сдача

Основание: [P1, с. 12–14](../Task/Постановка_кейса_—_Топливный_космоконтур_2035_КосмоХакатон_2026.pdf).
Здесь только структура будущих артефактов. Ни записка, ни эксперименты, ни презентация ещё не подготовлены.

| Требуется по постановке | Где готовить |
|---|---|
| Записка 8–12 страниц | [MANAGEMENT_NOTE.template.md](MANAGEMENT_NOTE.template.md) |
| Дополнительно одностраничное сравнение сценариев | [SCENARIO_SUMMARY.template.md](SCENARIO_SUMMARY.template.md) |
| Презентация до12 слайдов | [PRESENTATION_OUTLINE.md](PRESENTATION_OUTLINE.md) |
| Результаты, риски, stakeholders, KPI, источники, roadmap | [evidence.template.json](evidence.template.json), затем реальные артефакты в results |
| Код, конфигурации, планы обоих сценариев, тесты, export | Соответствующие каталоги приложения, после реализации |

В записку/презентацию переносить только результат с ID запуска и версией.
Дополнительно нужны схема цепочки снабжения; договорно-финансовая архитектура;
бюджет/дорожная карта2035–2040 с ответственными, зависимостями и инвестиционными воротами;
реестр рассчитанных рисков; карта интересов сторон; KPI с формулами и контролем.
Это можно оформить внутри записки/приложений, не обязательно в десятках отдельных файлов.

Поставка исходников организатора здесь через GitHub не меняет указанную в P1 передачу решения на GitVerse.
Перед сдачей проверить действующие организационные инструкции. Круглосуточный production и оборудование не требуются.
