# Передача: стабилизация веб-слоя из 9(1).zip

Scope: штатный запуск API, транспортные ошибки/версии, OpenAPI, тесты и инструкции backend → UI. Это не реализация frontend или математической модели.

`src/engine/`, `src/app/dto/calc_dto.py`, `src/app/service/calc_service.py`, `src/app/api/KosmoAPI.yaml`, исходные материалы и `sources.lock.json` не изменялись. В переносимый архив не включаются Git-метаданные, кэш Python, локальные проекты, виртуальные окружения и зависимости frontend. Исходный ZIP и исходный Git не переписываются.

## Изменения

В `main.py` удалены маркеры конфликта и импорт удалённого Hello, сохранён полноценный app factory с роутерами, middleware/CORS и хранилищем. В OpenAPI опубликован реальный единый формат ошибок; snapshot проверяется автоматически. Удаление Hello согласовано с текущим YAML Васи, его две расчётные операции совместимы по успешным схемам и operationId.

Внедряемый расчётный адаптер может передавать `engine_info` со стабильной версией. Ожидаемые публичные ошибки адаптера проходят до UI; неготовый шаблон/движок возвращает 503. Исключения программирования не раскрывают внутренние данные клиенту.

Установка и проверки backend больше не зависят от frontend-манифестов. В bootstrap добавлен `--backend-only`, а при отсутствии `uv.lock` используется локальный venv и существующие pinned requirements. `--full-check` запускает реальные pytest-тесты и проверку OpenAPI, а не только раннюю проверку каркаса.

Исправлены ссылки-дубликаты инструкций и устаревшие пути задач. Корневые README/START_HERE описывают текущую работу. Исторические планы и доказательства сохранены с обозначением их статуса; их прежние числа тестов не являются результатом этой передачи.

- `python -m pytest -q`: **106 passed**, без пропусков — [вывод](evidence/web-ready/pytest.txt).
- Реальный Uvicorn, loopback HTTP: **36 успешных проверок**, включая multipart-импорт, проекты/сравнение/JSON+CSV, конфликт ревизий, stale, сохранение после остановки и нового запуска процесса — [протокол](evidence/web-ready/live-http.json).
- `python tools/export_openapi.py --check`: актуальная схема, **20 операций** — [вывод](evidence/web-ready/openapi-check.txt).
- `python tools/workspace.py check`: целостность и навигация проходят — [протокол](evidence/web-ready/workspace-check.json).
- Синтаксис Bash и Python проверен; 58 защищённых файлов сверены побайтово с исходным архивом — [SHA-256](evidence/web-ready/protected-files.json).

```bash
python -m pytest -q
python tools/export_openapi.py --check
python tools/workspace.py check
```

**Границы проверки:** Docker и PowerShell в этой среде отсутствуют и не запускались. Чистая сетевая установка зависимостей не выполнена: попытка `uv lock` не завершилась в сетевом окружении за 25 секунд, файл lock не выдумывался. Проверены уже установленные точные версии из requirements и их зависимости — [среда](evidence/web-ready/environment.json). Bootstrap-тесты проверяют код/контракт скриптов, а не установку host tools на Windows/Linux.

Математическая корректность/V01–V10 не проверяется этой передачей. Сохранён существующий прототип. Локальные `.venv`, `node_modules`, `.local` и кэши исключены из обхода служебного workspace-check, но хеши защищённых источников продолжают проверяться. Тесты workspace не копируют виртуальные окружения и пользовательские проекты.

## Безопасный перенос

Полный архив распаковать отдельно. Overlay объединять с рабочим репозиторием после сверки исходных SHA-256: чужие новые изменения не перезаписывать. `.git` не заменять. В исходном архиве был unresolved merge; после проверки исправленного `main.py` пользователь отдельно отмечает конфликт разрешённым в своём Git. Эта передача не делает commit, reset, clean или push.
