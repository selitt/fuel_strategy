# Передача HTTP/UI-слоя на основе 6.zip

## Что принимать

Сохранён исходный контракт Васи; веб-часть добавляет импорт/валидацию JSON, проекты, ревизии и stale-state, сохранение результата, сравнение и выгрузку. Реализованы 22 HTTP-операции: 4 исходные и 18 дополнительных. Основная инструкция — [API_README.md](../../API_README.md).

Доменный код не переписан. Два изменённых Python-файла из исходного архива: `src/app/api/main.py` и `src/app/api/calc_controller.py`. В корневой README добавлен указатель на актуальный запуск. Остальное — новые файлы web-слоя/тестов/конфигурации/документации.

## Проверки

**63 API-теста прошли** (60 новых + 3 исходных). Полный набор: **89 passed, 3 исходных failed**; новых причин падения рабочего пространства нет. Отдельный Uvicorn-процесс: 9 успешных HTTP-проверок, включая сохранность после остановки и повторного запуска.

- Совместимость URL/operationId/JSON с `KosmoAPI.yaml`; реальный вызов существующего CalculationService.
- Официальные JSON Schema на выдаваемых конвертах, уникальные operationId и разрешимость OpenAPI `$ref`.
- Импорт, неверный ввод, finite numbers, дубли JSON-ключей, multipart и ограничения размера.
- JSON-проекты, повторное открытие, конкурентная запись, конфликт ревизий, stale результат, неизменность предыдущего результата при ошибке.
- Неполный ответ сервиса не превращается в default success/нулевые показатели.
- Экспорт сохраняет числа ядра; CSV сопровождается метаданными и защитой от формул; импортированный результат помечается unverified.
- Реальный Uvicorn + localhost TCP, multipart, расчёт, CSV ZIP; остановка и новый процесс с тем же каталогом открывают тот же проект.

Свежие результаты команд: [API](evidence/final-api-tests.txt), [все тесты](evidence/final-all-tests.txt), [исходное состояние](evidence/baseline-tests.txt), [реальный HTTP](evidence/live-http-smoke.json), [неизменность scope](SCOPE_VERIFICATION.json).

Полный набор включает три исходных падения `tests/workspace/test_workspace.py`: старый task index ссылается на отсутствующие `src/data_io`, `src/engine/physical`, `src/engine/economics`, `src/adapters`, `src/persistence`, `src/reporting`. Они уже были в 6.zip; не созданы фиктивные engine-модули ради зелёного статуса. Эти тесты не отключались.

Полный ZIP распакован в новую папку без Git/окружений: [API-тесты из архива](evidence/archive-api-tests.txt) и [полный набор из архива](evidence/archive-all-tests.txt) дают те же результаты. Защищённые исходники совпадают побайтово.

## Не проверено / не заявлено

Научная корректность модели, V01–V10, баллы жюри, полные lead-time/внутригодовые правила, стратегия закупок. Engine оставлен ровно как прислан.

Dockerfile/Compose присутствуют, но запуск Docker не выполнялся: в среде нет Docker. Чистая установка пакетов и сетевой `uv lock` не выполнены из-за отсутствия DNS-доступа к PyPI. Pins зафиксированы из реально проверенной Linux/CPython 3.13.5-среды, активные требования зависимостей проверены. Обстоятельства — [лог uv](evidence/uv-lock.txt), [замыкание зависимостей](evidence/dependency-closure.json).

Нет React-реализации, произвольного CSV/XLSX-import, авторизации, нескольких workers, фоновых jobs или телеметрии. Общий локальный workspace и синхронные сервисы, запускаемые FastAPI в threadpool.

## Следующий стык

Васе: сохранить существующие DTO/сервис или согласованно подключить новую реализацию через dependency; предоставить версию модели и обязательные поля результата. Математические поправки выполняются только владельцами engine.

Frontend: использовать расширенную [OpenAPI](openapi.json), типы из неё, `/api/meta`, `/api/catalog`, проектные операции и состояния из API_README. Не строить второй backend и не переносить формулы на клиент.

## Как переносить

Полный архив распаковывать в отдельную папку. Для действующей командной репозитории использовать overlay: сначала сверить base SHA-256 изменяемых файлов с manifest. Если коллеги уже изменили эти файлы или создали свои pyproject/requirements, объединить изменения вручную. В overlay нет engine, исходных DTO, calc_service и YAML Васи. Git-метаданные в переносимые архивы не включаются; исходный 6.zip и рабочая история не удалялись и не переписывались.
