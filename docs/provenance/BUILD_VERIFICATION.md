Команды:

```bash
python3 -S tools/workspace.py check
python3 -S -m unittest discover -s tests/workspace -v
```

`-S` отключает посторонние site/startup-пакеты окружения; самому helper нужны только модули стандартной библиотеки.
Обычные команды без `-S` описаны в README для стандартной среды.

Логи: [workspace_check.txt](workspace_check.txt), [helper_tests_green.txt](helper_tests_green.txt).
