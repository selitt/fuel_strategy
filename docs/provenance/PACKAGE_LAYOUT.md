# Состав архива

`START_HERE.md` — основной вход; `README.md` — обзор продукта.
`AGENTS.md` — постоянные правила для агента; `prompts/` — три рабочих запроса.
`docs/PRODUCT.md`, `ARCHITECTURE.md`, `regulation/` — продукт, границы и матрица регламента.
`tasks/` — T00–T08 и необязательный B01 с зависимостями; пять направлений без выдуманных имён.
`contracts/`, `src/`, `frontend/` — смысловые границы будущих модулей, не реализованные алгоритмы.
`configs/`, `plans/` — неисполняемые шаблоны предпосылок/плана.
`tests/acceptance/` — будущая приёмка; `tests/workspace/` — реально исполняемые проверки helper.
`tools/workspace.py` — служебные check/status/sources без сетевых действий.
`docs/deliverables/` — структура будущих материалов защиты.
`docs/Task/` и `fuel-hackathon/` — исходные материалы; другой кейс сохранён, но явно исключён.
`docs/provenance/` — байтовая сверка, происхождение, оригинальные метаданные и фактические протоколы.

Корневая структура следует рекомендуемым в постановке зонам src/tests/results/docs;
конкретные имена каталогов и организация tasks/prompts — соглашение этого каркаса, не новый регламент.
