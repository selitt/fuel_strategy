# Результаты будущего расчётного приложения

Сейчас расчётов нет. Не заполнять каталог придуманными KPI, оптимальными планами, нулевыми рисками или якобы пройденными тестами.
После реализации сохранять под идентификатором запуска: входы/версии, план, сценарий, допущения, результат,
проверки, протокол и экспорт. Один и тот же результат должен поддерживать интерфейс, записку и выгрузку.

Протокол проверки **самого каркаса** лежит в `docs/provenance/`, не является результатом решения кейса.
