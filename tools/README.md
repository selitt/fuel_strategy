# Служебные команды рабочего пространства

Стандартная библиотека Python, сторонние пакеты не требуются. Это не выбор Python для будущего приложения.
Из корня:

```bash
python3 tools/workspace.py check
python3 tools/workspace.py status
python3 tools/workspace.py sources
python3 -m unittest discover -s tests/workspace -v
```

Windows: заменить python3 на `py -3`.
Для изоляции от посторонних startup/site-пакетов можно добавить `-S` сразу после Python:
`python3 -S tools/workspace.py check` или `py -3 -S tools/workspace.py check`.

`--root` позволяет проверить другую распакованную копию; `--json` возвращает JSON.
Команда ничего не пишет, не скачивает, не устанавливает и не исправляет автоматически.
Проверяются8 областей: структура, хеши источников, переносимость путей/Git,
зависимости задач, ссылки критериев/направлений, связи приёмки/вопросов, синтаксис JSON и новая Markdown-навигация.

Не проверяются бизнес-формулы, безопасность реальной миссии, научная обоснованность стратегии, будущий frontend,
полная семантика JSON Schema, внешние ссылки или свежий clone настоящего remote.
Оригинальные ссылки организатора и прежние заметки сохранены, а их известные пробелы зарегистрированы отдельно.
